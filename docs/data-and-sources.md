# 数据来源与示例边界

## Olist 历史练习数据

- 数据集：[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)。
- 发布方：Olist and collaborators；本地下载日期 2026-10-25。
- 许可：[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)，署名、非商业性使用、相同方式共享；商业用途需另核授权。
- 数据时间为 2016—2018 年，不是实时订单；评价以葡萄牙语为主，机器译文不覆盖原文。
- 订单 99,441 行，评价 99,224 行；本地工作台实际练习范围不等于把全部记录逐条验收。
- 金额为 BRL。商品价格不含运费；支付金额不等于商品金额、利润或真实退款金额。
- 一个订单可能有多条商品、支付或评价，联查明细前需要按订单粒度聚合。
- 送达时效只在预计与实际日期齐全时计算；数据集不包含企业真实退款、赔付政策或商品成本。

原始数据不随本仓库分发。需要自行从原来源取得并遵循许可。现有工程中的 `backend/core/olist_import.py` 可供理解接入逻辑；目录与只读来源需在自己的环境配置，当前不声称一条命令即可重建原本地历史样本。

物流晚到、缺件追补和材料规则统一使用合成客户、合成订单与演示规则。项目里预置对话和审批用于解释流程，不能包装为企业真实成功案例。
